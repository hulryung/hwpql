동작 방식
How it works

3단계로 끝나는, 눈에 보이지 않는 공정 A quiet three-step pipeline

Rust로 파싱하고, SVG로 렌더하고, macOS 익스텐션으로 꽂습니다. 사용자 입장에선 그저 스페이스바 한 번입니다. Parse in Rust, render to SVG, plug into native macOS extensions — from your side, it's just a spacebar.

STEP 01

Rust로 HWP 파싱

Parse HWP in Rust

rhwp 크레이트가 HWP·HWPX 바이너리를 빠르고 안전하게 해석합니다.

The rhwp crate decodes HWP and HWPX binaries quickly and safely.

STEP 02

SVG + HTML로 렌더

Render to SVG + HTML

Swift는 FFI로 hwp_parse_to_html을 호출해 페이지를 SVG로 감싼 HTML을 받습니다.

Swift calls hwp_parse_to_html over FFI and gets back an SVG-wrapped HTML document.

STEP 03

Quick Look에 연결

Plug into Quick Look

프리뷰·썸네일 익스텐션이 시스템 패널에, 독립 뷰어가 WKWebView에 렌더링합니다.

Preview and thumbnail extensions feed the system panel; the standalone app renders inside a WKWebView.

설치 · 시작하기
Install · Get started

30초면 충분합니다. 30 seconds, start to finish.

둘 중 편한 방법으로 설치하세요. 설치 후 Finder에서 .hwp 파일 선택 → 스페이스바. Pick whichever you prefer. Then select a .hwp file in Finder and hit space.
